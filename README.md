# 分子観察鏡 | Digital Molecular Imaging System

授業用のシンプルな、8構造限定の3D分子観察サイトです。ユーザーが三次元分子・イオン・結晶モデルの向き・拡大率を自分で変えられます。

Web公開予定先： https://k-watanabe-chiba-u.github.io/molecule-explorer/
GitHubリポジトリ： https://github.com/k-watanabe-Chiba-U/molecule-explorer

## 今回の変更点

- タイトルを「分子観察鏡 | Digital Molecular Imaging System」に変更。
- メタンや二酸化炭素など、従来の6種類のサンプル分子を削除。
- Molecule Notes、How to Use、About This Project、ユーザーの一時的なXYZファイル読み込み欄を削除。
- 8つの講義用XYZファイルを**ファイル名順**に表示。8件を超えた場合、ファイル名順で9件目以降は表示しません。旧デモXYZが残っている場合は削除してください。
- モデル表示形式（球棒 / 棒 / 空間充填）、回転、リセット、前後の構造への移動、複数フレームXYZの再生は維持。

## 重要：実際の8座標ファイルは別途必要です

ご依頼に添付されていたのは研究計画書PDFのみで、8つのXYZ座標ファイルは含まれていませんでした。このZIPには構造の捏造・代用を避けるためXYZ本体は収録していません。**8つの.xyzファイルを登録すれば自動で機能します。**

## GitHub Pagesでの反映手順

1. このZIPを解凍します。
2. GitHubの `molecule-explorer` リポジトリを開きます。
3. `Add file` → `Upload files` から、ZIP内の以下の4ファイルをリポジトリ**最上位**にアップロードします。
   - `index.html` （既存ファイルを更新）
   - `styles.css` （既存ファイルを更新）
   - `app.js` （既存ファイルを更新）
   - `molecule-catalog.json` （以前追加済みなら更新、未登録なら新規追加）
4. `Commit changes` を押します。
5. `molecules` フォルダ（無ければ作成）を開き、**以前のテスト用 `hydrogen.xyz` 等が残っていたら削除**します。ここには今回表示したい**8個の.xyzファイルだけ**をアップロードしてください。
6. `Commit changes` で保存します。GitHub Pagesの公開処理後にサイトを更新してください。

### 並び順

各ファイルの先頭に `01_`、`02_` … `08_` と数字を付けておくと、**意図した順番**で表示されます。

例（以下は名称の例であり、今回の8構造の断定ではありません）：

```
molecules/
  01_水分子.xyz
  02_水素結合.xyz
  03_氷.xyz
  04_液体水.xyz
  05_水蒸気.xyz
  06_塩化ナトリウム.xyz
  07_Na水和.xyz
  08_Cl水和.xyz
```

ファイル名から「01_」などを取り除いた文字がボタンの名称として表示されます。実際の8つに合わせて、自由に変更できます。

## 設定

GitHubリポジトリの `Settings` → `Pages` で、`Build and deployment` → `Deploy from a branch`、`main`、`/(root)` を使用してください。Jekyllが `molecule-catalog.json` を自動作成するため、ルートに `.nojekyll` ファイルを作らないでください。

**動作確認ポイント**：サイトの `/molecule-catalog.json` を開くと、8件のJSON配列が表示されます。`{%` の文字がそのまま出る場合はJekyllが実行されていません。

## XYZについて

通常のXYZ形式：
```
3
H2O
O  0.0000  0.0000  0.0000
H  0.9572  0.0000  0.0000
H -0.2400  0.9266  0.0000
```

複数フレームが連結されたXYZファイルを使う場合は、原子数と原子順がすべて同じである必要があります。フレームが2つ以上の場合には再生バーが表示されます。1ファイル20 MB以下、1フレーム最大15,000原子、最大2,000フレームです。

XYZの原子間結合は描画ライブラリが距離などから推定します。溶液・結晶の「分子の動き」は、複数フレーム座標がない限り自動生成されません。

GitHubで公開した座標は誰でも取得できるため、未公開の研究データはアップロードしないでください。インターネット接続と3Dmol.js CDNへのアクセスが必要です。

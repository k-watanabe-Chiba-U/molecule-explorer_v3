# 授業で使う8構造のXYZファイル

ここに最大8つの `.xyz` ファイルを配置します。

**ファイル名の先頭に `01_` ～ `08_` を付ける**と、その順番で分子観察鏡の選択ボタンに表示されます。
例：

```
01_水分子.xyz
02_水素結合.xyz
03_氷.xyz
04_液体水.xyz
05_水蒸気.xyz
06_塩化ナトリウム.xyz
07_ナトリウムイオンの水和.xyz
08_塩化物イオンの水和.xyz
```

**上記は研究計画書に登場する題材に沿ったファイル名の例です。実際の8構造を指定するものではありません。** 提供された座標ファイルに応じた名称を使ってください。

追加した分子はこのフォルダ内でファイル名順に自動登録され、**サイト内には最大8件しか表示しません**。既存のメタン等のサンプルやXYZの手動アップロード機能はありません。
